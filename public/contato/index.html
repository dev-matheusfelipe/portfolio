Use seu perfil por aproximação

Aproxime o celular de uma tag já gravada.

Ilustração de uso. O site não transmite NFC entre celulares.

Grave o endereço abaixo em uma tag NFC física. Quando alguém aproximar um celular compatível, poderá abrir este perfil.

  1. 1
    Escolha a tag

    Use um cartão, adesivo ou chaveiro NFC que aceite registros de URL.

  2. 2
    Grave o endereço

    Em um aplicativo de gravação NFC, selecione URL e cole o link.

  3. 3
    Faça um teste

    Aproxime outro iPhone ou Android compatível antes de usar.

A aproximação funciona por meio da tag física. Uma página aberta no navegador não transmite o endereço diretamente para outro celular.

Este navegador não oferece gravação Web NFC. Use um aplicativo compatível para gravar a tag.
